# Recursos de Google Classroom

Esta carpeta contiene los archivos descargados del curso y su clasificación inicial.

- `documentos/`: PDF, DOC, DOCX y presentaciones.
- `imagenes/`: JPG, JPEG, PNG, WEBP, GIF y SVG.
- `hojas_de_calculo/`: XLS, XLSX, CSV y otros datos tabulares.
- `por_etapa/`: material clasificado según las etapas de `docs/ETAPAS OBRA`.

Los archivos se organizarán después de completar la descarga desde Google Classroom con una sesión autorizada.
